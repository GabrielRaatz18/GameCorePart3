## Apresentação em sala

Usamos o [roteiro de apresentação](roteiro-persistencia-room.md) para repetir os fluxos ao vivo:

1. Inserir e remover um jogo da Lista de desejos.
2. Publicar, editar e remover uma avaliação.
3. Fechar e reabrir o app para mostrar um registro mantido no Room.

No teste de reabertura, não limpamos os dados nem desinstalamos o aplicativo, pois isso apagaria o banco local.
